I created [Nuclear](https://nuclearplayer.com), and I also run [warmth.dev](https://warmth.dev), where I make audio plugins.

### Nuclear

<a href="https://github.com/nukeop/nuclear"><picture><source media="(prefers-color-scheme: dark)" srcset="https://raw.githubusercontent.com/nukeop/nukeop/master/cards/nuclear-dark.png"><img src="https://raw.githubusercontent.com/nukeop/nukeop/master/cards/nuclear-light.png" width="852" alt="nuclear"></picture></a>

[Nuclear](https://github.com/nukeop/nuclear) is a free, open-source music player
with no ads or tracking. It's available on Linux, macOS, and Windows. It has a plugin system, custom themes, and an MCP server for AI.
Built with Tauri (Rust + React).

### warmth.dev

<a href="https://warmth.dev"><picture><source media="(prefers-color-scheme: dark)" srcset="https://raw.githubusercontent.com/nukeop/nukeop/master/cards/warmth-dark.png"><img src="https://raw.githubusercontent.com/nukeop/nukeop/master/cards/warmth-light.png" width="852" alt="warmth"></picture></a>

[warmth.dev](https://warmth.dev) is my audio software label. I make effects and instruments for music producers (tape saturation, overdrive, chorus, delay, an electric piano, and more), shipped as VST3, CLAP, and AU plugins. They're built in Rust and egui, and available on [Gumroad](https://warmthdev.gumroad.com/), with both paid and free plugins.
